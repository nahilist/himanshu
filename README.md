# Nahilist — Himanshu Kumar's Portfolio

A high-performance, responsive, animated digital portfolio built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Production origin

The canonical production origin is `https://nahilist.vercel.app`, defined once in `lib/site.ts`. Metadata, Open Graph URLs, structured data, `robots.txt`, and `sitemap.xml` all use that origin.

If `himanshukumar.dev` or another owned domain serves the same site, configure a permanent host-level redirect (HTTP 308) to `https://nahilist.vercel.app` in the domain or hosting provider. Do not serve duplicate HTML from both origins. If a custom domain becomes the preferred origin later, update `SITE.origin` and redirect the Vercel domain to it before deployment.
